# Dark War:Survival

## Random BGB

![Dark War:Survival](./images/bg-B2dcFL5Z.webp)

Random BGB는 Dark War:Survival의 BGB A팀·B팀 참여자를 무작위 또는 입력 순서대로 선발하는 웹 앱입니다. 팀별 선발·예비·선정 탈락자와 두 팀에 중복 신청한 사람을 확인하고, 각 명단을 PNG로 저장할 수 있습니다.

`index.html`(BGB 인원 선발)과 `strategy.html`(BGB 전략 설계)은 브라우저에서 빌드 없이 열 수 있습니다. 상단 메뉴로 두 페이지를 오갈 수 있으며, 전략판은 지도와 배치 기능을 추가할 캔버스가 준비되어 있습니다.

공통 헤더의 제목 옆에서 **KO**(한국어) 또는 **EN**(영어)을 선택할 수 있습니다. 선택값은 브라우저의 `localStorage`에 저장되며 기본값은 EN입니다. 추첨 화면·PNG와 전략판의 사용 방법, 버튼, 지도 이름은 선택한 언어로 표시됩니다. 직접 지정한 타워 이름은 그대로 유지됩니다.

## 사용 방법

1. **Player slots**(기본 20명, 1~20명)과 **Reserve slots**(기본 10명, 0~10명)을 입력합니다. 같은 정원이 각 팀에 적용됩니다. **Team A Random**과 **Team B Random**은 기본으로 켜져 있으며, 끈 팀은 입력 순서대로 선발 인원과 예비 인원을 정합니다.
2. **Team A Applicants**, **Team B Applicants**를 펼쳐 한 줄에 한 명씩 입력하고 **Apply**를 누릅니다. 해당 팀의 목록을 현재 입력값으로 교체하며, 중복을 제외한 모든 이름이 체크된 상태로 표시됩니다. 빈 입력으로 확인하면 목록을 비웁니다. 체크 해제는 추첨 대상에서만 제외하고, **Remove**는 목록에서 제거합니다. 확인이나 삭제 후에도 입력창의 원문은 유지됩니다.
3. **Run Draw**를 누릅니다. 양쪽 팀에서 모두 체크된 이름은 두 팀 추첨에서 제외하고 **Duplicate Applicants**에 표시합니다. 제외 후 한 팀이라도 선발·예비 합계보다 인원이 적으면 추첨을 진행하지 않습니다.
4. 각 결과의 제목 줄을 눌러 명단을 펼칩니다. 랜덤을 켠 팀의 결과는 이름순, 끈 팀의 결과는 입력 순서로 표시합니다. 제목 줄 옆의 **PNG** 버튼은 목록을 접은 상태에서도 사용할 수 있습니다. 결과 화면과 PNG의 추첨 일시는 한국보다 11시간 느린 게임 서버 시간(UTC−02:00)으로 표시됩니다. 이미지에는 동일 명단의 누적 추첨 횟수와 해당 명단도 들어갑니다. 0명인 명단도 저장할 수 있습니다.

**Reset**을 누르고 확인하면 양 팀 명단, 설정, 결과, 이 탭의 추첨 기록을 모두 초기화합니다.

팀별 신청 목록 제목의 인원수는 `입력 인원수/체크된 인원수` 순서입니다. 목록은 기본 5행 높이에서 스크롤되며, 6명 이상이면 아래 화살표로 전체 목록을 펼치거나 다시 접을 수 있습니다.

## 임시 저장

양 팀 입력 원문과 등록 목록·체크 상태, 인원 설정과 팀별 랜덤 설정, 명단별 추첨 횟수는 브라우저의 `sessionStorage`에 저장됩니다. 같은 탭에서 새로고침하면 복원되며, 탭의 세션이 종료되면 임시 저장도 종료됩니다. 기존 단일 명단은 A팀 입력창과 목록에 복원됩니다. 추첨 결과는 새로고침 후 다시 뽑아야 합니다.

추첨 횟수는 A·B팀에서 체크된 신청자 조합별로 성공한 추첨만 누적합니다. 인원 설정이나 등록되지 않은 입력 원문만 바뀌면 횟수를 유지합니다. 체크된 명단이 달라지면 별도로 기록하며, 이전 조합으로 돌아오면 그 횟수를 불러옵니다.

입력한 명단은 브라우저 안에서 처리됩니다. 브라우저가 임시 저장을 차단하면 화면에 안내가 표시되며, 새로고침 시 입력 내용이 사라질 수 있습니다.
